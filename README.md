## 🚀 Como rodar o projeto

Este é o módulo Mobile (React Native + Expo) do sistema de estoque.

### Pré-requisitos
Para o funcionamento completo, é necessário que o **Backend** esteja rodando.
- **Repositório do Backend:** [Estoque-Java](https://github.com/AndersonKN011/Estoque-Java)

### Instalação
1. Clone este repositório.
2. Execute `npm install` ou `yarn install`.
3. Certifique-se de alterar a `API_URL` no código para o IP da sua máquina.
4. Execute `npx expo start`.
